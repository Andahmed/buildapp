## 2) خريطة Python AI Engineering (صفحة The World of Data)

**الخلاصة:** خريطة 11 محور لأدوات بناء أنظمة AI كاملة (بيانات → ML → LLM →
RAG → وكلاء → MLOps → نشر → تقييم → أمان) مع نصيحة: مش لازم تعلم كل حاجة —
ابدأ من الأساس واتدرج، والقيمة في اختيار الأداة المناسبة لحل مشكلة حقيقية.

**موقفنا منها — مطابقة المحور بمحور:**

| المحور | عندنا في المشروع | القرار |
|---|---|---|
| RAG & Retrieval | `src/lib/rag.ts` — BM25-lite + FTS | مطابق — vector DB (Chroma/Qdrant) مؤجل لحد ما الكورس يكبر |
| AI Agents | `src/lib/agent.ts` + بوابات أدوات | مطابق |
| Evaluation | `scripts/evals.ts` — قياس موثق 4.30→4.76/5 | مطابق — وإحنا بنثبت بالأرقام |
| Deployment | Dockerfile + Caddyfile + `docs/DEPLOY.md` | مطابق |
| Security | `net-guard.ts` (SSRF) + AES-256-GCM للمفاتيح + تسجيل دخول إلزامي | مطابق |
| LLMs | مزودين متعددين (Gemini/OpenRouter/z-ai) | مطابق — فجوة محتملة: **Ollama fallback** للشغل المحلي بدون إنترنت |
| Monitoring/Tacing | سجلات داخلية بس | **أضعف محور عندنا** — أول تحسين مرشح بعد النشر |

**القرار:** فكرة، مش دمج عاجل. ناخد منه حاجتين بالترتيب: تتبع التجارب والقياس
الحبيبي، ثم Ollama كـ fallback — بعد ما النشر يخلص ويشتغل الأجل طبيعي.

## 3) Estella — محرك ألعاب مفتوح يشتغل بالـ MCP (صفحة Pinoyfreecoder) ⭐ الأخطر

**الخلاصة:** محرك ألعاب 2D/3D مفتوح المصدر (TypeScript SDK + نواة C++/WebAssembly
+ محرر مرئي) — **المحرر مكشوف أدواته عبر MCP**، يعني الوكيل الذكي (زي وكلائنا)
يقدر فعلياً: ينشئ مشاهد وكيانات وprefabs وtilemaps، ياخد screenshots، يفتش
في المشهد، يشغّل اللعبة ويحاكي إدخال ويعمل playtests مرتبة، ويولّد sprites
وموسيقى وموديلات 3D — ونشر من مشروع واحد لـ ويب/ديسكتوب/**WeChat**/Android/iOS.

**التحقق (مصدر أصلي):**
- الريبو: `esengine/estella` — **Apache-2.0**، **1105 نجوم**، اللغة الأساسية **TypeScript**، آخر دفعة 18 نوفمبر 2026.
- تفاصيل الترخيص (من المنشور): الـ runtime والـ SDK مفتوحين، المحرر المرئي منتج مجاني **مغلق المصدر**، وتكامل Spine له ترخيص منفصل.
- التعليقات بتذكر بدائل بروحها: Godot وUnity وUnreal عندها MCP plugins — دي كلام التعليقات، لسه ماتأكدتش منها.

**الفايدة — مرتبطة مباشرة باسم الريبو الجديد `ai-mobile-game-studio`:**
1. **مرشح #1 لأداة "مطور الألعاب" في المكتبة:** موظف AI جديد أو ترقية موظف
   موجود يبني لعبة كاملة عن طريق أدوات الـ MCP في Estella — ويعمل playtest
   مرتب وياخد screenshot **كالدليل** — نفس قاعدتنا: مفيش ✅ بدون دليل.
2. **TypeScript ECS = نفس لغة مشاريعنا** — الدمج أسهل بكتير من أي محرك C#/C++.
3. **نشر WeChat MiniGames** = سوق ضخم محدش بيغطيه من المحركات الغربية — ميزة تنافسية حقيقية.
4. **بديل محتمل:** Godot + MCP plugin — ناضج أكتر ومجتمع أكبر، قرار الاختيار
   ينتظر تجربة عملية على الاتنين (لعبة صغيرة 2D كاملة بالوكيل).
