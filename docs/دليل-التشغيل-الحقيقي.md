| رفع صور وتحليلها بالرؤية | ✅ شغال حقيقي | صورة اترفعت واتحللت فعلًا (نماذج رؤية GLM) |

### ضمانة "مفيش شغل وهمي" (أهم حاجة في التحديث ده)

كان فيه ثغرة: الموديل ممكن يقول «عملت الملف» من غير ما ينفذ. اتسدت نهائيًا:

1. المحرك بيفحص نص المهمة نفسه — لو بتطلب ملف/تقرير/سكريبت، **ممنوع التسليم** من غير ملف حقيقي على القرص.
2. لو الموديل حاول يسلم كلام — المحرك يجبره ينفذ `write_file` فعليًا.
3. لو ما نفذش — **المحرك يكتب الملف بنفسه** من نتائج الخطوات الحقيقية ويسجّل ده في اللوج.
4. كل خطوة بتنفيذها بتنور مباشرة في تبويب «المهام» مع سجل تنفيذ لحظي وملفات للتحميل.

## 2) مفتاح Gemini بتاعك — الحالة الصادقة بالكامل

المفتاح بتاعك اتجرب فعليًا من سيرفر التطبيق السحابي:

- ✅ **المفتاح سليم 100%** — الـ auth بيجيب وبينفع.
- ⚠️ **جوجل بترجع توليد الردود من المنطقة الجغرافية للسيرفر السحابي** (خطأ معروف: `User location is not supported for the API use`). ده حجب من جوجل نفسها على الـ IP ده تحديدًا.
- ✅ **على جهازك في مصر المفتاح هيشتغل فورًا** (مصر منطقة مدعومة).
- ✅ لما مفتاحك مش قادر يخدم، المشروع **بيكمل تلقائيًا** بالمحرك المجاني المباشر بدون ما تحس — بس العقل بيتبدل والواجهة بتقول لك مين شغال.

**إزاي تخلي مفتاحك هو اللي شغل؟** شغّل المشروع على جهازك (القسم 4) — أو حط مفتاح **OpenRouter** (مفتاح واحد بيوصل لنفس موديلات Gemini + عشرات الموديلات التانية، وطبقته المجانية مفتوحة من السيرفر ده — اتاختبرت فعليًا: HTTP 200 و476 موديل متاحين).

## 3) سلسلة العقول (من غير أي توقف)

```
1) مفتاحك المتصل (Gemini أو أي مفتاح حطه من تبويب المفاتيح)
        ↓ لو فشل لأي سبب
2) محرك مجاني مباشر بدون مفتاح (Pollinations — متوافق OpenAI)
        ↓ لو اتحد معدل الطلبات (1 رد كل 45 ثانية)
3) المحرك المدمج GLM (سريع ومجاني)
```

- التبديل **تلقائي وفوري** ومسجل في لوج السيرفر برسالة واضحة.
- الواجهة بتعرض «العقل الشغال دلوقتي» في الهيدر وفي تبويب المفاتيح — بالاسم الفعلي.
- مفيش أي ردود مزروعة: الرد إما من نموذج حقيقي أو رسالة خطأ واضحة.

### مصفوفة المزودين — متختبرة فعليًا من سيرفر التطبيق (curl حقيقية)

| المزود | النتيجة من السيرفر السحابي | طبقة مجانية |
|---|---|---|
| Google Gemini | مفتاحك سليم لكن حجب جغرافي على الـ IP السحابي | مجاني من AI Studio |
| OpenRouter | ✅ واصل بالكامل (476 موديل) | فيه 20+ موديل مجاني `:free` |
| DeepSeek | ✅ واصل | رخيص جدًا |
| SiliconFlow (صيني) | ✅ واصل | فيه موديلات مجانية (Qwen) |
| Moonshot Kimi (صيني) | ✅ واصل | مدفوع رخيص |
| Zhipu GLM (صيني) | ✅ واصل | `glm-4-flash` مجاني |
| Mistral | ✅ واصل | طبقة مجانية ضخمة (~1 مليار توكن/شهر) |

| Pollinations | ✅ واصل — **بدون أي مفتاح** | مجاني بالكامل |

## 4) تشغيل المشروع على جهازك (هنا مفتاحك هو البطل)

```bash
# متطلبات: bun أو node 20+
bun install
bun run db:generate

# ملف البيئة المحلي — حط مفتاحك هنا
echo 'GEMINI_API_KEY=مفتاحك' >> .env.local
echo 'GEMINI_DEFAULT_MODEL=gemini-flash-latest' >> .env.local

bun run db:push
bun run dev
# افتح http://localhost:3000
```

من أول تشغيل: المشروع هيقرأ مفتاحك من `.env.local` ويسجله تلقائيًا في الشركة (مش ظاهر كامل لأي حد — متقنّع في الواجهة ومتخزن على جهازك بس)، وكل الشات والمهام هتشتغل بعقلك مباشرة.

## 5) جسر OpenManus الرسمي (اختياري — على جهازك)

الحزمة اللي انت رفعتها (`openmanus-employee-bridge`) بتشغّل وكيل **OpenManus الرسمي** (github.com/FoundationAgents/OpenManus — 59,003 نجمة، رخصة MIT) كخدمة Python، وتطبيق Next.js بيتكلم معاها:

```bash
# 1) انسخ مفتاحك في .env.openmanus (GEMINI_API_KEY=مفتاحك)
# 2) على جهازك:
git clone --depth 1 https://github.com/FoundationAgents/OpenManus.git OpenManus
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r OpenManus/requirements.txt
pip install -r openmanus_bridge/requirements.txt
bash openmanus_bridge/start.sh
curl http://127.0.0.1:8001/healthz

# 3) في .env.local لتطبيق Next.js:
OPENMANUS_BRIDGE_URL=http://127.0.0.1:8001/chat
OPENMANUS_BRIDGE_TOKEN=نفس الرمز اللي في .env.openmanus
```

ملاحظات مهمة:
- الجسر ده بيشتغل على جهازك **فقط** — على السيرفر السحابي العمليات الخلفية مش دائمة، عشان كده المحرك المدمج بأسلوب OpenManus (خطة → أدوات → ملاحظة → تسليم) هو اللي شغال هنا، ونفس فلسفة التنفيذ بالظبط.
- جوجل هي نفسها بتطبق الحجب الجغرافي — فعلى جهازك في مصر الجسر والمفتاح هيشتغلوا مع بعض.
- مفيش سيرفر محلي بيحتاج متصفح Playwright افتراضيًا (`OPENMANUS_DISABLE_BROWSER_USE=1`) — آمن وخفيف.

## 6) الأمان

- مفاتيحك بتتخزن على جهازك/السيرفر بتاعك فقط، وبتتقنّع في الواجهة (`AQ.A••••j1pw`).
- المفتاح عمره ما بيتكتب في الواجهة الأمامية ولا بيبعت للناس.
- تنفيذ Python/الملفات بيحصل في مجلد معزول بمهلة زمنية (30 ثانية) — والاتصال من السيرفر السحابي محمي بالبوابة.
- مفيش تسجيل دخول عام — لما تنشر للناس ضيف auth (NextAuth جاهز في المشروع).
