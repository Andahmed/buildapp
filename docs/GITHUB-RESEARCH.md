آخر تحديث: 2026-11-22 — البيانات جمعت مباشرة من GitHub API (باقي الحقول من صفحات GitHub/npm بعد انتهاء حصة الـ API).

## خلاصة القرارات (مرحلة B)

الدمج الفعلي في الجلسة دي (فكرة→كود عندنا، بدون نسخ كود — الأسباب فوق):
1. **Rate-limit gate لـ Pollinations** (فكرة LiteLLM: تجنب 429/402 قبل حدوثها) — محرك Pollinations محدود بـ 1 رد/45 ثانية لكل IP؛ بنسجل وقت آخر رد ناجح ولو الاتصال جاي في النافذة بننتقل فوراً للمحرك اللي بعده بدل ما نحرق 45 ثانية ونكشف 402.
2. **BM25-lite في rag.ts** (فكرة LlamaIndex/sqlite-vec: ترجيح بالندرة IDF + تطبيع طول المستند) — بدل TF البسيط.
3. **محرك DuckDuckGo IA** في web_search (فكرة Crawl4AI: محركات احتياطية متعددة) — API رسمي مجاني بدون مفتاح.
4. **سيناريوهات تقييم + حكم LLM** (فكرة OpenAI Evals/Reflexion) — `scripts/evals.ts` بيطلع تقرير أرقام في docs/EVALS-REPORT.md.

اللي اتقرر تجاهله له أسباب تشغيلية/رخص موثقة فوق — مش "مفيش وقت".

ممنوع النسخ من: Firecrawl وSearXNG (AGPL-3.0)، Firejail (GPL-2.0)، Dify (رخصة مخصصة مقيدة).
