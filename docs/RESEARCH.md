## المصدر 1: Habr (habr.com) — 2026-11-22 — الحالة: 🔄 قيد التنفيذ (البحث والتطبيق مقاسين، والباقي لجلسات جاية)

### الخلاصة (5 أسطر)
1. أقوى فكرة عملية اتطبقت: **Preflight ميزانية التوكنات** (مقالة Bitrix24) — طلبات أكبر من نافذة المحرك بتعمل 400/هنج بدل رد صريح، فالفحص قبل الضرب أرخص من العلاج بعده. اتنفذت في `src/lib/providers.ts` برفض محلي **0.001ms** بدل مهلة 45ث.
2. مقالة Yandex للتاستيل: فصل prefill/decode وكاش KV ومعه راوتر بيدور على الكاش رفعت إصابة الكاش لـ **54%**، والـ TTFT نزل **-76%** (36.9ث→8.8ث) بالتوازي السياقي — ناخد منها "ناخد فكرة": إعادة استخدام السياق المشترك بدل إعادة إرساله.
3. **خلل streaming حقيقي موثق**: 5% من ردود SGLang JSON ناقص لأن المعالج بيغسل الـ buffer بعد أول عنصر — نفس عائلة مشكلتنا "رد مكسور في النص"؛ العلاج عندنا: قاعدة برومبت v3.2 (الخلاصة الأول + ممنوع رد مكسور) + preflight يمنع الزحمة.
4. مقالة Bitrix24 قالت: زيادة نافذة السياق 64k→85k عالجت **73.5%** من الأخطاء بس والذيل فضل — يعني الحل مش "سياق أكبر" بل فحص الميزانية + ملخصات. ده غيّر قرارنا: مش هنوسّع سياق، هنقص مدخلات.
5. أدوات اتشاف فيها واترفض: vLLM/SGLang (بنية سيرفر مخصص — مش قابلة للدمج في sandbox)، Langfuse/Phoenix/OpenLIT (خدمات تتبع منفصلة — رفض بنفس سبب Dify في GITHUB-RESEARCH.md، ناخد الفكرة: لوجات spans بسيطة في الرد المقاس).

## المهام 16+17 من Habr — الجلسة السادسة (2026-11-22): تسجيل الدخول + الفحص الشامل

**المهمة 16 — ثغرات Next.js/Prisma/SQLite الشائعة (اتقفلت كلها):**

1. **مفيش تسجيل دخول (Critical — كان أخطر ثغرة في المشروع):** أي حد يعرف رابط النشر كان هيستخدم مفاتيح المزودين + أداة python + الـ agent. **الإصلاح المنفذ اليوم:**
   - `src/proxy.ts` — بوابة على كل مسار (صفحات + API + SSE): بدون جلسة صالحة → تحويل لـ `/login` أو `401 JSON`، وبدون إعداد → **فشل مغلق** (`307 err=config` للصفحات، `503` للـ API).
   - جلسة موقّعة HMAC-SHA256 (`src/lib/auth.ts`) — `HttpOnly + SameSite=Lax + Secure` على HTTPS، صلاحية أسبوع، **صفر حالة على السيرفر**.
   - `src/app/api/auth/login` — كلمة سر واحدة من البيئة (أقل من 8 حروف = الدخول مقفول)، مقارنة ثابتة الزمن (`timingSafeEqual` بعد SHA-256)، حد معدل **8 محاولات غلط / 15 دقيقة لكل IP → 429**.
   - زر «خروج» في الهيدر + معترض 401 عام في الواجهة بيحوّل لأي انتهاء جلسة لصفحة الدخول فوراً.
   - **الدليل المقاس:** `scripts/test-auth.sh` — **11/11 PASS** على build إنتاجي standalone (307/401 SSE/503 config/403 غلط/كوكي مزور/HttpOnly/دخول 200/429 بعد 8/خروج max-age=0) + اختبار الفشل المغلق يدوي (307 err=config + 503 JSON).
2. **حقن SQL:** صفر `$queryRaw`/`$executeRaw` في src/ (`rg -c` = 0) — Prisma parameterized بالكامل.
3. **Mass assignment في التعيين:** `/api/hr/hire` بيقبل `jobDescription` بس، وكل حقول الموظف متولدة/مفلترة على السيرفر (`VALID_DEPTS` + `VALID_TOOLS` + `slice`).
4. **Path traversal في الملفات:** `diskName` = UUID + امتداد متقطع، والقراءة بـ `path.basename` (موجود، اتحقق منه اليوم).
5. **CSRF:** الكوكي `SameSite=Lax` — POSTs عابرة للمواقع مش بتبعت الجلسة.
6. **الـ robots.txt كان بيسمح بفهرسة كل حاجة** — اتصلح اليوم: `User-agent: * / Disallow: /` (مكتب خاص).

**المهمة 17 — فحص الحماية (مفاتيح/SSRF/حقن/رفع/XSS) — كلها خضرا:**

- **مفاتيح:** كل الردود متقنعة (`••••`) في `/api/keys` و`/api/keys/[id]`، والتخزين AES-256-GCM (`src/lib/crypto.ts`) — اتحقق منه بالقراءة.
- **SSRF:** `bun run scripts/test-ssrf.ts` — **8 محاولات: 7 حجب** (localhost/127.0.0.1/192.168.x/169.254.169.254 metadata/10.x/file:/[::1]) **+ رابط عام واحد مسموح** — بتاريخ اليوم.
- **Sandbox:** `bun run scripts/test-sandbox.ts` — CALC ✓ NET-BLOCK ✓ REQ-BLOCK ✓ ENV-CLEAN ✓ — بتاريخ اليوم.
- **XSS:** `react-markdown` بيهرّب المحتوى افتراضياً، و`dangerouslySetInnerHTML` اتنين بس: سكريبت تسجيل service-worker ثابت (layout.tsx) + متغيرات الثيم القياسية في مكتبة shadcn (chart.tsx) — مفيش مدخلات مستخدم جواهم.
- **رفع الملفات:** UUID للأسامي + تنقية الامتداد (12 حرف، `[^.\w]` متشال) + قراءة بـ basename.
- **طبقة الدخول الجديدة بتقفل كل الـ APIs (بما فيها SSE والـ python tool)** — أي ثغرة مستقبلية في منطق الأدوات لازم تعدّي عليها الأول.
